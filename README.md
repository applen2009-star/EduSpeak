# 🌐 EduSpeak - Master English Landing Page

A secure, highly responsive, and pixel-perfect landing page designed for a modern English learning platform.

## 🚀 Features
* **Responsive Design:** Seamless layout beautifully optimized for desktop, tablet, and mobile devices.
* **Interactive Cards:** Smooth hover animations and dynamic interactions in the "Why Choose Us?" section.
* **Form Validation:** Real-time email input verification with instant feedback and custom toast notifications.
* **Smooth Navigation:** Seamless scrolling experience across sections and a functional "Back to Top" button.
* **Cybersecurity Shield:** Built-in anti-clickjacking protection and foundational XSS defense.

## 🛠️ Technologies Used
* **HTML5** - Semantic web structure.
* **CSS3** - Modern layout styling, custom gradients, and fluid transitions.
* **JavaScript (ES6+)** - Event-driven interactive logic, local storage system, and form state management.
